# Savings goal math (education)

If target = T, already saved = S, monthly pledge = P:

- Remaining = T − S
- Months needed ≈ ceil((T − S) / P) when P > 0
- Required monthly pledge for D months ≈ ceil((T − S) / D) when D > 0

This is arithmetic only. It does not include investment returns, inflation, or product recommendations.

If months needed exceed the deadline, lower T, raise P only after needs are covered, or extend the date.
